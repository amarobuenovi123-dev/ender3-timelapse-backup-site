Privacy Policy

Last updated: October 20, 2026

1. Purpose

Ender3 Timelapse Backup is a personal application used to back up timelapse recordings from a 3D printer to the owner's Google Drive account.

2. Google Drive Access

The application requests the Google Drive drive.file permission. This allows it to create and manage files and folders accessible to the application.

3. Data Processing

The application processes timelapse videos, file names, and metadata necessary for organizing and transferring backups.

Google OAuth credentials are stored locally on the owner's device for authentication.

4. Data Sharing

The application is intended for personal use. It does not sell personal information or use Google Drive data for advertising.

Files are transferred directly between the owner's device and Google Drive through the Google Drive API.

5. Data Retention

Backed-up videos remain in the owner's Google Drive account until deleted by the owner or by an explicitly configured retention process.

6. Access Control

The owner can revoke the application's Google Account access at any time using Google Account security settings.

7. Contact

Questions about this personal integration can be directed to the application developer through the contact email displayed on the Google OAuth consent screen.
